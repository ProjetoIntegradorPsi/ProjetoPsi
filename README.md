## 📌 Sobre o projeto

O projeto consiste no desenvolvimento de um sistema de monitoramento integrado para o Laboratório de Piscicultura da Universidade Federal de Santa Maria (UFSM), no campus de Camobi.

Atualmente, o monitoramento dos tanques é realizado de forma manual e periódica, o que pode dificultar a precisão dos registros e atrasar a identificação de possíveis falhas nos equipamentos responsáveis pelo suporte ao cultivo dos peixes.

Diante desse problema, o projeto propõe uma solução tecnológica capaz de realizar a coleta automática de dados dos tanques e dos equipamentos, permitindo o acompanhamento das informações em tempo real por meio de um Dashboard Web.

## 🎯 Objetivo

Desenvolver um sistema de monitoramento para auxiliar no acompanhamento das condições dos tanques e no diagnóstico de falhas técnicas nos equipamentos utilizados no Laboratório de Piscicultura da UFSM.

## 🐟 Funcionalidades

- Monitoramento de temperatura: coleta da temperatura da água utilizando o sensor DS18B20.
- Monitoramento de pH: acompanhamento do nível de pH da água dos tanques.
- Monitoramento elétrico: medição de tensão e corrente dos equipamentos utilizando o INA3221.
-  Monitoramento de equipamentos: acompanhamento de equipamentos de suporte, como bombas e aquecedores, auxiliando na identificação de possíveis falhas.
-  Dashboard Web: apresentação dos dados coletados de forma visual e organizada.
- Armazenamento dos dados: envio e armazenamento das informações coletadas para posterior consulta e análise.
- Acesso via QR Code: QR Code integrado ao gabinete permite acessar rapidamente o Dashboard por meio de um smartphone.
- Monitoramento contínuo: coleta e envio periódico das informações dos sensores para o sistema.
